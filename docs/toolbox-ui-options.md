# 工具站 UI 候选

当前工具站的主要任务是查找并使用几十个工具，包含文本输入、文件处理、加密结果和独立服务入口。优先考虑清晰导航、搜索、长时间阅读和窄屏使用。

| 方案 | 适用部分 | 需要调整 |
| --- | --- | --- |
| **FlowMate（首选）** | 固定分类侧栏、米白背景、右侧工具目录，容易容纳搜索、收藏和最近使用 | 将品牌营销内容换成工具卡片，工具编辑区域保留足够宽度；原仓库没有完整页面截图 |
| **Modern HR Dashboard** | 浅色工作台、圆角卡片和清楚的状态层级，适合把首页变为个人工具面板 | 移除人事统计与装饰图表，黄色仅作少量强调色，改成分类或常用工具卡片 |
| **Dashboard UI** | 深色卡片网格，适合喜欢暗色主题的工具目录 | 背景视频和较重玻璃效果应减弱；正文、输入框和代码结果使用实底面板 |

Taskly 的柔和紫色玻璃球可作为首选方案的小面积视觉点缀。其仓库缩略图是装饰素材，不能当作完整网页预览。推荐最终以 FlowMate 的信息布局为主，动效保持克制，工具输入和结果区采用清晰的实底样式。
