# Finlytic AI Agent

A responsive implementation of the hero described in `PROMPT.md`. Design ID: `finlytic-ai-agent`. Built with vanilla HTML, CSS and JavaScript, using Vite 7.3.7. The prompt does not prescribe a framework.

The page includes the exact hero copy, requested font families, purple CTAs, glass dashboard frame, black blurred element and supplied animated globe video. Desktop dimensions follow the prompt; mobile uses smaller type and a collapsible navigation menu. Services, account buttons, demo, reviews and contact open keyboard-accessible dialogs. Forms validate locally and clearly identify themselves as previews.

## Build and run

With Node 22.12+ and npm:

```sh
npm ci
npm run build
npm run preview
```

The site is mounted at `/motionsites-results/finlytic-ai-agent/`. All runtime assets are local, and the production output is in `dist/`, including `dist/index.html`. No deployment or push was performed.

On the supplied host, use the existing Docker image:

```sh
docker run --rm -u 1000:1000 -e HOME=/tmp -v "$PWD:/work" -w /work --entrypoint sh louislam/uptime-kuma:2 -c 'npm ci && npm run build'
```
